# Трекер смен (PWA)

## Назначение
Приложение для учёта рабочих смен, расчёта зарплаты и переработок. Разработано с подходом offline-first как PWA, работает полностью локально без необходимости в сервере или аккаунте.

## Стек технологий
- React 18
- Vite
- TypeScript
- Vite PWA Plugin (Workbox)
- IndexedDB + localStorage для локального хранения
- Lucide React (Иконки)

## Особенности архитектуры
- Отсутствие серверной зависимости для основных функций
- Удалена функциональность регистрации и профилей, оставлены только настройки приложения (сохраненные локально)
- Кэширование всех необходимых ресурсов (HTML, JS, CSS, иконки) для полноценной работы без интернета

## Инструкции по разработке и запуску

1. **Установка зависимостей**
   `npm install --legacy-peer-deps`

2. **Запуск сервера для разработки**
   `npm run dev &`

3. **Production сборка (и генерация Service Worker)**
   `npm run build`

4. **Запуск собранной версии (Preview)**
   `npm run preview &`

## Офлайн режим
- При первой загрузке (если есть сеть) Service Worker кэширует все ресурсы
- Данные сохраняются в `localStorage`
- Приложение можно установить как PWA (добавить на рабочий стол)
- Приложение полностью функционально (добавление, редактирование смен, настроек) без интернета
